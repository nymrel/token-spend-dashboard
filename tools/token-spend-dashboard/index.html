Questions, answered plainly

Before you ask

How do I get a usage CSV from my AI provider?

In the Anthropic Console, open Usage and export CSV. In the OpenAI Platform, open Usage and export your activity. Then paste the file here or choose it from your computer.

Do I need an account or an API key?

No. Token Ledger reads a file you already have. There's no login, no API key, and nothing is uploaded to a server.

What if my export has no cost column?

It estimates spend from token counts using an editable price table. The rates are clearly labeled estimates — you can correct any model's input and output price, or add a model it doesn't know. Your edits are saved in this browser.

Is my data safe?

Yes. Everything is processed in your browser — nothing you paste or load is ever sent to a server. Your pasted data disappears when you close the tab; only your price-table edits and preferences are saved locally in this browser, and “Reset to defaults” clears them.

Which providers and formats work?

Any CSV with a date, a model, and token or cost columns. Token Ledger auto-detects common Anthropic and OpenAI export headers (like input_tokens, completion_tokens, cost) and lets you remap any column by hand.
